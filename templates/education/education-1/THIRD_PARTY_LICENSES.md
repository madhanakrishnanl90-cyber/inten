# Third-Party Licenses & Attributions

This project incorporates design concepts, visual interaction primitives, and components inspired by open-source libraries under permissive licenses.

## 1. React Bits
- **Source**: [https://reactbits.dev](https://reactbits.dev)
- **License**: MIT License
- **Description**: Lightweight animated UI components, interaction hooks, and layout primitives built with React, Tailwind CSS, and Motion.
- **Included Components**:
  - `SpotlightCard` (Radial spotlight cursor tracking)
  - `TiltedCard` (3D Parallax tilt effect)
  - `CountUp` (Viewport-triggered numeric incrementation)
  - `LogoLoop` (Infinite linear marquee animation)
  - `BeamsBackground` / `AuroraBackground` (Interactive luminous ambient lighting)
  - `GradientText` & `SplitText` (Typographic gradient treatments)
  - `Stepper` (Interactive progression timeline)
  - `CardSwap` / `TestimonialStack` (Layered stack card transition)
  - `MagicBento` (Multi-cell bento grid with spotlight borders)
  - `Accordion` (Accessible collapsible disclosure items)
