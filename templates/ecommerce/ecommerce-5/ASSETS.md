# Asset Provenance & Documentation

This document outlines the origins, specifications, and commercial licensing status of all brand assets, images, icons, and fonts used within the **VÉRA Fashion E-Commerce Template**.

---

## 1. Brand Identity

- **Brand Name**: **VÉRA**
- **Type**: Fictional demonstration brand created exclusively for this template.
- **Logo Mark**: Original geometric typography mark rendered using `Playfair Display` serif font and CSS styling.
- **Trade Status**: No trademark claims or real-world brand imitations.

---

## 2. Imagery System

All image references are managed centrally in `src/data/products.ts` and stored in `public/assets/images/`.

| Asset File / Reference | Origin | License / Usage |
| :--- | :--- | :--- |

## Replacing Template Imagery

Purchasers of this template can swap demo product photos by updating the data model in `src/data/products.ts` or replacing the files inside `public/assets/images/`.
